Add to Chrome ↗

Make yourself at home.

  1. Add the extension.Open the Chrome Web Store listing, select Add to Chrome, and confirm the installation.
  2. Open Instagram.Visit Instagram and sign in to your account. If it is already open, refresh the page.
  3. Meet your dashboard.Select Dashboard in Instagram’s sidebar. Your feed now has room to breathe.

Good to know.

Do I need an Instagram account?

Yes. The extension uses your existing signed-in Instagram session to load your home feed. You do not need a separate dashboard account or an Instagram API key.

Is Instagram Dashboard free?

Yes. You can install Instagram Dashboard for free from the Chrome Web Store.

What if my feed stops loading?

Try reloading Instagram first. Instagram can change its internal endpoints or navigation, so an extension update may sometimes be needed.
