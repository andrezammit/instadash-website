Good to know.

Do I need an Instagram account?

Yes. The extension uses your existing signed-in Instagram session to load your home feed. You do not need a separate dashboard account or an Instagram API key.

Is Instagram Dashboard free?

Yes. You can install Instagram Dashboard for free from the Chrome Web Store.

Can I still use Instagram Messages?

Yes. Instagram’s Messages button and conversations stay accessible while you browse the dashboard. You can hide the button in Settings.

Can the whole dashboard go full screen?

Yes. Enter full-screen mode from the dashboard header, and optionally hide the header in Settings. You can also choose whether Dashboard opens manually, opens automatically on Home, or restores its last visibility state.

How do I leave full-screen mode?

Press Esc to return to the normal dashboard view. If you enable “Hide header in full screen mode” in Settings, the header appears again when you leave full screen.

What if my feed stops loading?

Stalled requests time out, and failed requests retry automatically with a delay. If the problem continues, try reloading Instagram. Instagram can change its internal endpoints or navigation, so an extension update may sometimes be needed.
